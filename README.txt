FARUQ LENS — TIMELESS FRAMES

Website portofolio fotografi, videografi, dan editing.

Cara upload ke GitHub Pages:
1. Ekstrak ZIP ini.
2. Buka repository GitHub faruq-lens.
3. Upload seluruh isi folder faruq_lens_website (index.html dan folder assets) ke root repository.
4. Jika diminta, pilih Replace files dan Commit changes.
5. Tunggu GitHub Pages selesai deploy, lalu refresh website.

Galeri Timeless Frames sudah berisi 10 foto dokumentasi konser. Jangan mengubah nama file di folder assets tanpa memperbarui jalur src di index.html.
